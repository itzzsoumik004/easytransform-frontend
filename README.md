# 📖 About

EasyTransform is an online file conversion platform that allows users to convert, compress, resize and edit PDF and Image files directly from their browser.

The project is designed with a clean user interface, responsive layout and fast backend processing.

No software installation is required.

# 💻 Installation

## Clone Repository


```bash

```

```bash

```

## Backend

```bash
npm install
```

```bash
npm start
```
